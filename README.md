## How I work

- **Start with the need.** Turn stakeholder needs into requirements, compare concepts, and define how to check the result.
- **Build and test.** Use models, code, or physical prototypes to check assumptions before making larger decisions.
- **State the limits.** Keep simulation separate from field evidence. Make uncertainty and human review explicit.

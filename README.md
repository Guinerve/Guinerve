## About me

I'm Nicholas, an engineer and software builder in Canberra. I work on renewable energy, physical prototypes and software. I like clear requirements and results that someone else can check.

Most of my projects start with one question. How far does grid frequency fall when a big generator trips? Do prediction market prices mean what they say? I build the smallest thing that answers it, test it against real data, and write down where it stops working.

## How I work

- **Start with the need.** Turn what people need into requirements. Compare concepts. Decide how to check the result before I build it.
- **Build and test.** Use models, code or physical prototypes to test assumptions before a large decision.
- **State the limits.** Keep simulation apart from field evidence. Say what is uncertain and where a person must review.

**Software:** Python · TypeScript · React · FastAPI · SQL · Docker · scikit-learn · Git

**AI:** Local LLMs (Ollama, Open WebUI, omlx) · a private home AI setup over Tailscale · retrieval augmented generation · model evaluation · MCP servers

**Engineering:** Requirements · Trade studies · Test plans · Power flow · KiCad · CAD · 3D printing
